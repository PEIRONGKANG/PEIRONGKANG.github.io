# The Romance of Research — Rongkang Pei

Personal academic homepage for Rongkang Pei, a doctoral researcher in Computational Humanities and Sociology at Tohoku University.

The site is a responsive, static, four-language profile in English, Japanese, Traditional Chinese, and Simplified Chinese. It can be opened locally from `index.html` or served directly with GitHub Pages.

## Local preview

```bash
python3 -m http.server 8765
```

Then open <http://127.0.0.1:8765>.

## Deployment

The repository is designed for GitHub Pages at <https://peirongkang.github.io/>.
